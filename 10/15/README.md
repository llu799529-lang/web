# web2

课程作业：使用 CSS 变量、Grid 布局、CSS 图标规则新建网页。

## 规则
- **CSS 变量**：所有颜色、尺寸集中定义在 `:root`，组件内一律用 `var(--x)` 引用。
- **Grid 布局**：图标本体使用 `display: grid`，3 列 × 4 行。
- **CSS 图标**：用 `<div>` 像素格拼出字符矩阵。

## 图标矩阵
```
a b b
c b b
c d e
c d f
```

## 色板映射
| 字符 | 变量 | 颜色 |
|------|------|------|
| a | `--a` | transparent（透明） |
| b | `--b` | #5b8def 蓝 |
| c | `--c` | #3b5bdb 深蓝 |
| d | `--d` | #fab005 黄 |
| e | `--e` | #40c057 绿 |
| f | `--f` | #fa5252 红 |
