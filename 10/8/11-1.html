CSS 长度单位

px 像素

绝对单位，1px = 1 物理像素（屏幕）

width: 200px;

em

相对于当前元素字体大小（16px 时 1em=16px）

width: 12.5em; (font-size: 16px)

rem

相对于根元素 html 的字体大小

width: 12.5rem;

vw 视口宽度

1vw = 视口宽度的 1%

width: 25vw;

% 百分比

相对于父元素宽度的百分比

width: 75%;

cm 厘米

物理长度单位，1cm ≈ 37.8px

width: 5cm;

mm 毫米

物理长度单位，1mm = 1/10 cm

width: 50mm;

in 英寸

物理长度单位，1in = 2.54cm = 96px

width: 2in;

pt 磅

印刷单位，1pt = 1/72 in

width: 150pt;

pc 派卡

印刷单位，1pc = 12pt

width: 12.5pc;

ch

当前字体中 "0" 字符的宽度

width: 20ch;

vmin

视口宽高较小值的 1%

width: 20vmin;

vmax

视口宽高较大值的 1%

width: 15vmax;

ex

当前字体中小写 x 的高度

width: 25ex; (font-size: 16px)
