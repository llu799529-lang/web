JavaScript 程序结构 · 条件 · 循环

程序只有三种基本结构：顺序、分支、循环。下面每个例子的绿色框， 都是页面加载时真的跑了一遍这段代码算出来的结果，不是手写的文字。

GitHub 仓库

顺序结构

代码从上往下一行行执行，前一步的输出就是后一步的输入，最基础的结构。

分支结构

根据条件决定走哪条路：if / else if / else、三元运算符、switch 都属于这一类。

循环结构

条件成立就重复执行：for、while、do...while、for...of，配合 break / continue 控制。

一、条件（分支结构）

if / else if / else 成绩评级

function grade(score) {
  if (score >= 90) return 'A';
  else if (score >= 80) return 'B';
  else if (score >= 60) return 'C';
  else return 'D';
}

三元运算符 一句话判断

let n = 7;
let type = n % 2 === 0 ? '偶数' : '奇数';

switch 多分支匹配

switch (day) {
  case 6:
  case 0:  text = '周末'; break;
  default: text = '工作日';
}

顺序结构 从上到下

let price = 39.9;
let count = 3;
let total = price * count;   // 先算小计
if (total > 100) total *= 0.9;  // 再判断是否打折

二、循环（循环结构）

for 1 到 10 累加

let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}

while 不知道次数时

let n = 100, steps = 0;
while (n > 1) {          // 偶数除 2，奇数乘 3 加 1
  n = n % 2 === 0 ? n / 2 : n * 3 + 1;
  steps++;
}

do...while 至少执行一次

let i = 10;
do {
  log.push(i);
  i++;
} while (i < 3);

for...of + break 遍历数组

for (const n of [3, 8, 15, 22]) {
  if (n > 10) break;   // 超过 10 就停
  picked.push(n);
}

三、嵌套：九九乘法表前 3 行

for (let i = 1; i <= 3; i++) {
  let line = '';
  for (let j = 1; j <= i; j++) line += `${j}×${i}=${i * j}  `;
  table.push(line);
}
