JavaScript 数组的主要方法

数组就是一排有序的格子，每个格子有编号（索引，从 0 开始）。下面把方法的作用直接画成格子的变化： 新增是绿的、删掉是红的并划掉、命中是黄的、留下是蓝的。 每一处结果都是页面打开时真实算出来的，不是手写的文字。

GitHub 仓库

一、数组长什么样 索引从 0 开始，length 是格子个数

let fruits = ['苹果', '香蕉', '橙子', '葡萄'];
fruits[0]        // 取第一个：'苹果'
fruits.length    // 4

二、增删元素 都会直接改动原数组

push / pop / unshift / shift 首尾增删

let a = ['苹果', '香蕉', '橙子'];
a.push('葡萄');      // 末尾加，返回新长度
a.pop();             // 末尾删，返回被删的那个
a.unshift('西瓜');   // 开头加
a.shift();           // 开头删

push / unshift 返回新长度，pop / shift 返回被删掉的那个元素。

splice 任意位置增删改

let b = [10, 20, 30, 40, 50];
// splice(起始索引, 删几个, 插入什么…)
b.splice(1, 2, 'X', 'Y');

三、查找与判断 只读，不改数组

indexOf / lastIndexOf / includes / find / findIndex 找得到吗、在第几个

let c = ['苹果', '香蕉', '橙子', '香蕉'];
c.indexOf('香蕉');                  // 第一次出现的位置
c.lastIndexOf('香蕉');              // 最后一次出现的位置
c.includes('橙子');                 // 有没有，返回 true / false
c.find(v => v.length === 2);        // 第一个满足条件的元素
c.findIndex(v => v === '橙子');     // 第一个满足条件的索引，找不到是 -1

四、遍历与转换 不改原数组，返回新的东西

map 一个换一个

每个元素过一遍函数，返回等长的新数组，一个不多一个不少。

let d = [1, 2, 3, 4];
d.map(n => n * 10);

filter 按条件筛

函数返回 true 的留下，返回 false 的被剔掉，长度会变。

let e = [7, 12, 3, 19, 8, 25];
e.filter(n => n > 8);

forEach 挨个处理一遍

和 for 循环差不多，但不返回值，只是把每个元素拿去用。

let f = ['苹果', '香蕉', '橙子'];
f.forEach(function (v, i, arr) {
  console.log(i + ': ' + v);   // 依次 0:苹果 1:香蕉 2:橙子
});

reduce 把一排揉成一个

从左往右累积：上一次的结果，拿去和下一个元素算。

let g = [1, 2, 3, 4, 5];
g.reduce((sum, n) => sum + n, 0);

五、排序与转换 注意 sort 默认按字符串比大小

sort 排序，要用比较函数

let h = [10, 9, 100, 25];
h.slice().sort();               // ['10', '100', '25', '9']
h.slice().sort((a, b) => a - b); // [9, 10, 25, 100]

reverse 倒过来

let i = [1, 2, 3, 4];
i.reverse();   // 原数组也被改了

下图为了保住原数组，先 slice() 复制了一份再 reverse；真按上面代码写，i 自己也会变成 [4,3,2,1]。

join 接成字符串

let j = ['a', 'b', 'c'];
j.join('-');    // 'a-b-c'
j.join('');     // 'abc'

slice / concat / at 不动原数组

let k = [1, 2, 3, 4, 5];
k.slice(1, 3);       // [2, 3]
k.concat([6, 7]);    // [1,2,3,4,5,6,7]
k.at(-1);            // 5
