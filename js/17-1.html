JSON 的结构与用法

JSON（JavaScript Object Notation）就是一种把数据写成文本的格式：前后端传数据、存配置、调接口， 基本都用它。它只有对象和数组两种容器，值只能是下面这六种，没有函数、没有注释、没有 undefined。

GitHub 仓库

一、一条 JSON 长这样 大括号是对象，方括号是数组，里面都是键值对

  • 键必须是双引号："name" 可以，name 和 'name' 都不行。
  • 值只能是六种：字符串、数字、布尔、null、对象、数组，不能是函数或 undefined。
  • 对象用 { } 包住一组键值对，数组用 [ ] 按顺序排一串值。
  • 最后一项后面不能加逗号，这一点和 JS 对象不同。
  • 不能写注释，// 和 /* */ 都会让解析失败。

二、JSON 只认这六种值

字符串 string
"张三"

必须用双引号，单引号不合法。

数字 number
18 / 3.14 / -2e10

整数小数科学计数法都行，没有引号。

布尔 boolean
true / false

小写，不能写成 True。

空值 null
null

表示“没有”，没有 undefined 这个东西。

对象 object
{ "a": 1 }

无序的键值对集合，用大括号。

数组 array
[1, "a", true]

有序的列表，类型可以混着放。
